# Security Policy

## Supported versions

libgfx is before 1.0 and has no tagged releases yet. Security fixes go into the `main` branch.

| Version        | Supported |
|----------------|-----------|
| `main` (0.1.x) | Yes       |
| Older commits  | No        |

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately through the
repository's **Security** tab, under **Report a vulnerability**.

Include what is affected (file, function or API) and the commit you tested, the smallest program
that reproduces it, and your platform: operating system, GPU and driver, and compiler.
